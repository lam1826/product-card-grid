# Portfolio cá nhân — HTML5 & CSS3

Bài tập tốt nghiệp HTML/CSS đa trang với thiết kế Mobile-First.

## Cấu trúc

- `index.html`: trang chủ với Hero và CTA
- `about.html`: giới thiệu, kỹ năng, hành trình học tập
- `projects.html`: 3 thẻ dự án có ảnh minh họa (SVG nội bộ)
- `contact.html`: form HTML minh họa (chưa kết nối backend)
- `css/style.css`: toàn bộ CSS bên ngoài, có breakpoint 768px và 1024px
- `images/`: 3 ảnh SVG minh họa tự tạo

## Chạy thử

Mở `index.html` qua Live Server của VS Code. Kiểm tra cả 4 trang ở chiều rộng 375px, 768px và 1024px.

## Xuất bản trong repository bài tập

Đặt nguyên thư mục `portfolio-personal` vào thư mục gốc của repository `lam1826/product-card-grid`, sau đó commit và push lên nhánh `main`.

Link GitHub Pages dự kiến sau khi deploy:

https://lam1826.github.io/product-card-grid/portfolio-personal/

## Lưu ý

- Trang có nội dung minh họa, cần thay thế bằng tên và thông tin cá nhân thực tế trước khi gửi tuyển dụng.
- Form liên hệ chỉ là giao diện HTML, chưa gửi email. Cần backend hoặc dịch vụ form để hoạt động thực tế.
- Không dùng framework, không dùng JavaScript, không dùng inline/internal CSS.
