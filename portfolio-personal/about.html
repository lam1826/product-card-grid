VỀ PORTFOLIO NÀY

Học, thực hành và phát triển từng ngày.

Trang này giới thiệu quá trình rèn luyện kỹ năng làm web. Bạn có thể thay thế nội dung mẫu bằng thông tin cá nhân, học vấn và kinh nghiệm thực tế trước khi gửi nhà tuyển dụng.

Về tôi

Mình đang học xây dựng giao diện web với HTML5 và CSS3. Mình quan tâm đến trải nghiệm người dùng, cấu trúc mã nguồn dễ bảo trì và khả năng truy cập trên mọi thiết bị.

Định hướng tiếp theo là nâng cao JavaScript và phát triển các sản phẩm web hoàn chỉnh hơn.

Kỹ năng của tôi

  • HTML5 Semantic
  • CSS3
  • Flexbox
  • CSS Grid
  • Mobile-First
  • Media Queries
  • Git & GitHub
  • DevTools

Hành trình học tập

  1. Thực hành HTML ngữ nghĩa, bảng biểu và biểu mẫu
  2. Thiết kế component với Box Model, trạng thái hover và Position
  3. Xây dựng lưới Responsive với Flexbox, Grid và Media Queries
  4. Hoàn thiện dự án Portfolio đa trang và chuẩn bị xuất bản
